# AI Research OS Dashboard Architecture v1

## Goal

将研究资产、市场数据、Agent分析和复盘结果统一展示。

## Modules

### 1. Overview
- Market status
- Watchlist alerts
- Pending reviews
- Research confidence changes

### 2. Stock Detail

For each ticker:
- Current price
- Research history
- Bull/Base/Bear scenarios
- Current decision
- Thesis breakers
- Next review date

### 3. Agent Performance

Track:
- Agent score
- Historical accuracy
- Error categories
- Calibration quality

### 4. Knowledge Graph

Display:
- Insights
- Rules
- Source research
- Validation results

## Design Principle

Dashboard is not a trading terminal. It is a decision support system.

The main question is:

What changed, does it affect the thesis, and what action should follow?
