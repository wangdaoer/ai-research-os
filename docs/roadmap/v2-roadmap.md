# AI Research OS v2 Roadmap

## v2.1 — Memory and Decision Core
- Research Memory schema
- Decision Record schema
- Research Rule schema
- Backtest Record schema
- Immutable versioning convention

## v2.2 — First Live A-share Case
- Select one watchlist company
- Run all research agents
- Create approved research record
- Create decision and review schedule
- Generate investment and content outputs

## v2.3 — Local Data Integration
- Import watchlist CSV/JSON
- Import A-share review dashboard exports
- Validate field mappings and data quality
- Generate normalized local datasets

## v2.4 — Dashboard
- Research queue
- Company memory timeline
- Agent scorecard
- Decision ledger
- Rule library
- Backtest and calibration metrics

## v2.5 — Automation
- Weekly article ingestion
- Scheduled thesis review
- Earnings update workflow
- Rule candidate extraction
- Multi-output content generation

## Definition of Done for v2
A research item can move from source ingestion through multi-agent analysis, human-approved decision, memory update, public content generation, scheduled review and measured outcome without losing provenance or rewriting history.
