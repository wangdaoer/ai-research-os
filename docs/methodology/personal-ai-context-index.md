# 个人 AI 总控系统：上下文索引

> 作用：让任何接入本仓库的 Agent、工具或协作者，在开始工作前理解系统目标、资料位置、输出规范和边界。  
> 最后更新：2026-10-19  
> 维护原则：事实变更即更新；不把临时聊天内容当作长期规则。

## 1. 系统使命

AI Research OS 用于把 AI、A 股、科技商业与创业效率相关的信息，转化为可检索、可评分、可追踪、可复盘的研究资产。

核心闭环：

```
输入资料 → 结构化研究 → 形成判断 → 人工审批 → 跟踪结果 → 复盘并更新规则
```

## 2. 当前优先工作流

| 工作流 | 目标 | 主要产物 | 主要目录 |
| --- | --- | --- | --- |
| AI 模型、Agent 与工具研究 | 识别可测试的产业变化与工具机会 | 周报、研究卡、内容选题 | `research/`、`knowledge/insights/` |
| A 股与投资研究 | 将信息转化为研究假设、风险与跟踪项 | 公司/行业研究、复盘记录 | `knowledge/companies/`、`knowledge/industries/`、`research/` |
| 研究方法沉淀 | 统一研究质量与复盘方式 | 模板、评分卡、规则 | `templates/`、`knowledge/rules/`、`docs/methodology/` |
| Agent 工作流 | 将稳定任务拆成可验证的 Agent 流程 | 提示词、工作流、评估记录 | `agents/prompts/`、`agents/workflows/`、`agents/evaluation/` |

## 3. 资料与真相来源

按以下优先级判断信息是否可作为结论：

1. 一手来源：公司公告、监管文件、财报、产品官方文档、原始数据。
2. 可交叉验证的权威报道或行业数据。
3. 经明确标注的分析、推断与假设。
4. 未验证的线索只能进入待核实清单，不能写成结论。

时间敏感信息必须标注日期与来源；投资、价格、政策、产品能力和可用性默认视为时间敏感。

## 4. 目录导航

| 目录 | 放什么 | 不放什么 |
| --- | --- | --- |
| `knowledge/` | 可复用知识、洞察、公司与行业资料、规则 | 未经整理的临时聊天全文 |
| `research/` | 带日期的日度、周度、专题、公司或行业研究 | 与研究无关的开发草稿 |
| `templates/` | 可复制的研究卡、评分、复盘模板 | 已完成的实际项目记录 |
| `agents/` | Agent 提示词、流程、评估与运行规则 | 密钥、账号或未经确认的高权限配置 |
| `data/` | 可追溯的结构化数据与导入样例 | 敏感个人数据、密钥、不可公开的原始文件 |
| `docs/` | 方法论、系统说明、运行与治理规则 | 每次执行产生的临时输出 |

## 5. 输出标准

每份研究优先回答四个问题：

1. 发生了什么？
2. 为什么重要？
3. 下一步值得验证或测试什么？
4. 会改变什么研究假设、行动或内容选题？

研究结论需区分：

- **事实**：有来源、可复核。
- **判断**：基于事实的解释。
- **假设**：尚待验证的可能性。
- **行动**：具体、可执行、可验收。

## 6. Agent 运行约定

- 默认先读本文件和任务相关目录，再开始执行。
- 先给出可逆、低风险成果；涉及外部发送、发布、付费、删除或真实投资动作时必须请求人工确认。
- 新建或修改重要文件时，应在结果中列出路径、用途和验证方式。
- 不保存 API Key、密码、验证码、身份证件或其他敏感信息到仓库。
- 具体权限规则见：[Agent 权限分级与执行记录](../agent-guides/agent-permission-policy.md)。
