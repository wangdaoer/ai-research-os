# AI Research OS Dashboard Frontend Specification v1

## Goal

Build a research cockpit for AI-assisted A-share investment research.

## Pages

## 1. Overview

Components:
- Market status
- Watchlist alerts
- Pending reviews
- Recent research updates
- Agent confidence changes

Primary question:
> What changed today that may affect investment decisions?

## 2. Stock Research Page

Example: 300750

Sections:
- Investment thesis
- Bull/Base/Bear scenarios
- Agent opinions
- Valuation assumptions
- Risks
- Tracking indicators
- Historical reviews

## 3. Agent Center

Display:
- Agent score
- Historical accuracy
- Error patterns
- Industry strengths

## 4. Knowledge Center

Display:
- Insights
- Rules
- Research relationships
- Validated lessons

## Design Principle

The dashboard should not optimize for information quantity. It should optimize for decision quality.
