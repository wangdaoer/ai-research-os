# AI Research OS

面向 AI、A股、科技商业与创业效率研究的结构化研究操作系统。

## 核心目标

将文章、财报、观点、研究结论和复盘转化为可检索、可评分、可追踪、可迭代的长期资产。

## 核心流程

数据输入 → 多 Agent 分析 → 市场共识识别 → 预期差判断 → 概率与估值 → 仓位决策 → 人工审批 → 持续跟踪 → 结果复盘 → 规则更新

## 目录

- `templates/`：研究卡片、Agent 评分、复盘模板
- `schemas/`：统一 JSON Schema
- `knowledge/`：文章、洞察、公司与行业知识
- `research/`：日度、周度、公司与行业研究
- `agents/`：Agent 提示词、评估与工作流
- `data/`：自选股、市场数据与研究历史
- `docs/`：方法论、Agent 指南、投资框架
