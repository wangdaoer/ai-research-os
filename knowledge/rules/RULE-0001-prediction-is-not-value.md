# RULE-0001 — 预测正确不等于创造价值

## 状态
Active

## 规则
只有当研究判断相对于市场共识具有可验证的增量，并且对应价格、概率与仓位形成正向风险收益比时，预测才具有投资价值。

## 适用范围
- Agent 评估
- 个股研究
- 估值
- 组合决策
- 复盘

## 强制检查
1. 当前价格已反映了什么？
2. 我们与市场的分歧是什么？
3. 分歧是否有独立证据？
4. 概率加权预期收益是否为正？
5. 下行风险和仓位是否匹配？

## 证据
- 首篇 LLM forecasting agents 研究卡片：模型方向预测接近，但下注收益显著分化。

## 例外
不适用于纯知识问答或不涉及资金配置的预测任务。
