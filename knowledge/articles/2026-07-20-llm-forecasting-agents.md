## 一句话结论

预测方向接近并不意味着经济价值接近；真正拉开 Agent 表现差距的是概率校准、价格意识、仓位纪律和诚实复盘。

## 核心观点

1. 多模型结论高度一致，可能说明它们共享相似信息源与市场锚，而非形成独立判断。
2. 预测正确率相近时，仓位与赔率管理仍可造成显著收益差异。
3. 复盘文字流畅不等于真正承认错误，错误识别能力应单独计分。

## 对系统的影响

- 新增 Agent Scorecard。
- 个股研究必须填写市场共识、核心分歧、情景概率和仓位。
- 多 Agent 应按数据与方法分工，而不是重复提问。
- 研究数据库必须保存原始预测，禁止事后覆盖。
