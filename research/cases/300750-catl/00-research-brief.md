## 决策问题

在2026年半年度报告发布后，宁德时代未来12–24个月的盈利增长、现金流、资本开支、全球化扩张与储能业务，是否足以支持相对于当前价格的正向风险收益比？

## 已确认公开事实

1. 公司于2026年7月25日披露2026年半年度报告及摘要。
2. 2026年上半年营业收入为2769.17亿元，同比增长54.80%。
3. 2026年第一季度营业收入为1291.31亿元，同比增长52.45%；归母净利润207.38亿元，同比增长48.52%。
4. 公司披露2026年中期现金分红方案：以扣除回购专户股份后的股本为基数，每股派发现金红利14.11元（含税）。
5. 公司同期披露新的A股回购方案。

## 首轮研究假设

- H1：动力电池与储能需求增长可继续推动收入与利润扩张。
- H2：规模、技术、供应链与客户结构仍构成竞争壁垒。
- H3：全球化扩张、资本开支与贸易政策可能压低自由现金流或提高风险溢价。
- H4：即便公司基本面优秀，若当前价格已充分反映增长，仍可能缺乏投资赔率。

## 必须回答的问题

### Fundamental Agent
- 上半年利润、经营现金流和自由现金流的增长是否匹配？
- 毛利率、费用率、减值、政府补助及非经常性损益如何变化？
- 资本开支、在建工程与产能利用率是否匹配？

### Industry Agent
- 全球动力电池与储能需求的可验证增长来源是什么？
- 竞争格局是否恶化？价格压力是否被技术和规模优势抵消？
- 海外政策、关税、本地化生产与客户集中风险如何变化？

### Valuation Agent
- 当前A股价格、总市值、企业价值及2026–2028年一致预期是多少？
- 市场价格隐含的收入、利润与自由现金流增长率是多少？
- 牛/基准/熊情景下的合理价值区间是什么？

### Market Agent
- 近3、6、12个月相对创业板、沪深300及新能源指数表现如何？
- 机构持仓、融资交易、成交拥挤度与重大事件预期如何？

### Bear Agent
- 哪些条件会使增长、利润率、现金流或估值逻辑失效？
- 哪些风险尚未被市场充分计价？
